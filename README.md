# 🌸 CELLU-CARE™ - Landing Page & Admin Dashboard (COD Morocco)

صفحة هبوط (Landing Page) احترافية وعالية التحويل لمنتج **فرشاة تدليك ونحت السيلوليت** مخصصة للتجارة الإلكترونية والدفع عند الاستلام (Cash On Delivery) في المغرب، مع **لوحة تحكم كاملة للمسؤول (Admin Dashboard)** لإدارة وتأكيد وتصدير الطلبات.

---

## 🚀 المميزات الرئيسية (Features)

### 🛍️ صفحة هبوط الزبائن (Landing Page)
- **تصميم عصري متجاوب 100%:** مخصص للهواتف الذكية والحواسيب.
- **لغة عربية سليمة (RTL):** نصوص تسويقية مدروسة مع خطوط جوجل (`Cairo` و `Tajawal`).
- **معرض صور تفاعلي:** استعراض المنتج وصور السبا وطريقة الاستخدام.
- **مؤقت العد التنازلي (Urgency Timer):** لتحفيز الشراء السريع.
- **باقات العروض الخاصة:** اختيار عرض حبة واحدة (189 درهم) أو حبتين (299 درهم).
- **استمارة طلب COD سريعة:** مع قائمة منسدلة لأهم المدن المغربية وتحديث فوري للمجموع.
- **زر الطلب المباشر عبر واتساب:** يفتح محادثة جاهزة بالمعلومات بنقرة واحدة.
- **شريط سفلي مثبت للهواتف (Mobile Sticky Bar):** لتسهيل الطلب في أي وقت.
- **إشعارات شراء لحظية (Social Proof Toast):** تعزز ثقة الزائرين.

---

### 🔐 لوحة تحكم الأدمين (Admin Dashboard)
- **تسجيل دخول آمن:**
  - **اسم المستخدم (Username):** `admin`
  - **كلمة المرور (Password):** `12345678`
- **مزامنة الطلبات الحية:** ظهور فوري للطلبات الجديدة في الجدول مع تنبيه صوتي (Audio Chime).
- **أزرار التواصل السريع:**
  - 📞 **اتصال مباشر:** للاتصال الفوري بهاتف الزبونة.
  - 💬 **واتساب مباشر:** محادثة جاهزة لتأكيد العنوان والشحن بالدارجة المغربية.
- **تحديث حالة الطلب:** (🟡 في الانتظار | 🟢 مؤكدة | 🚚 قيد الشحن | ✅ تم التسليم والدفع | 🔴 ملغاة).
- **إحصائيات المبيعات (KPIs):** إجمالي الطلبات، المبيعات بالدرهم (MAD)، والطلبات النشطة.
- **تصدير Excel (CSV):** تحميل ملف منظم لشركات التوصيل (Cathedis, Ameex, Ozone, إلخ) بضغطة زر.

## 🛠️ طريقة التشغيل محلياً (Installation & Setup)

1. **تشغيل الخادم:**
   ```bash
   node server.js
   ```
2. **الروابط:**
   - متجر الزبائن: `http://localhost:3000/`
   - لوحة تحكم الأدمين: `http://localhost:3000/admin`
